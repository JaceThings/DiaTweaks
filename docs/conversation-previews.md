# Claude, Gemini and T3 Chat previews

Enable each provider separately in Settings → Tabs. Hover its Dia tab to see up to three conversations from the website's sidebar, plus one separate preview pin. Whole-row clicks select the website tab before opening the conversation. Pinning affects the preview only. Titles truncate within the same compact native hover container as ChatGPT.

These experimental adapters use the shared conversation renderer, scheduler, commands and cache policy. They collect only sidebar titles, conversation links and supported status markers; they do not read message bodies, cookies, tokens or authentication stores. No website API requests are made. Missing markup becomes unavailable rather than being treated as a confirmed empty list. Loading has a six-second limit. Claude and Gemini do not yet have a verified empty-account marker, so a blank sidebar is treated as unavailable and cannot erase scoped fallback data. T3 guest mode also checks its Login footer and sidebar busy indicator before reporting an empty list.

| Website | Current source and status support | Cache and pin boundary |
| --- | --- | --- |
| Claude | Recent sidebar chat links and separate website-pinned candidates; working follows the observed `data-attention="working"` row marker. Unread is not yet supported. | Account identity has not been confirmed in Dia's script context. Live metadata and a document-local preview pin work; persistent pins and cached fallback remain disabled. |
| Gemini | The native conversations list and its title elements. Website-pinned rows remain pin candidates without consuming recent slots. Working and unread are not yet supported. | A visible Google account email label scopes memory-only cached metadata and an ID-only persistent pin. Without the label, only live metadata and a document-local pin are used. Account labels are not sent to any service. |
| T3 Chat | Sidebar thread links and the thread-title input value, in sidebar order. Working, unread and exclusion of website-pinned threads are not yet supported. | Confirmed guest mode uses a unique document scope for memory-only fallback and a document-local pin. The scope is withdrawn when the Login footer disappears. Signed-in identity is not yet confirmed, so signed-in fallback is uncached and its preview pin remains document-local. |

Cached data is labeled **Cached**, hides live status indicators, permits opening links and disables pin changes. The shared cache is per provider, page and browser, and expires after one hour. Navigation, disable, disposal and ownership changes clear it. A missing identity boundary clears fallback metadata; unavailable data with the same confirmed scope can retain the last good list. A cached snapshot never supplies a fabricated working or unread state.

Live inspection on November 4, 2026 verified Claude and Gemini recent lists, T3's guest thread, and the preview pin command on all three pages. A short sidebar-only observation captured Claude's working marker appearing and disappearing together with its native Stop response control. T3's background page returned its collector result after being selected. Model activity/unread transitions on Gemini and T3, Claude unread, and signed-in T3 account transitions remain unverified. The original ChatGPT adapter retains its existing behavior.

The installed shared navigation path was also exercised through the production preview actions on ChatGPT, Claude, Gemini and T3. Each selected a different existing conversation, focused its target tab and reached the selected URL in the actual web contents, then restored the preceding page and tab. Checks waited for navigation to commit and reacquired current scripting-window snapshots; the scripting URL property alone was not used as the success signal.

Run `make test-integrations test-chatgpt` for collector validation, script packaging, native policy/cache checks and the existing framework/ChatGPT regressions. These tests use synthetic metadata and observed structural selectors; they do not replace live site checks. Do not commit personal titles, conversation IDs, account labels or message content as fixtures.
