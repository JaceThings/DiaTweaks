## Turn it on

Open **Dia → Settings → Patches** and switch on **Hide sidebar button**. Or run:

```sh
diatweaks enable hideSidebarButton
```

## Works with

While [Hide toolbar](hideToolbar.md) is on, the button is hidden with the rest of the toolbar and this switch is greyed out in Settings. With [Reveal toolbar on hover](revealToolbarOnHover.md) too, the button stays hidden when the toolbar shows, as long as this tweak is on.
