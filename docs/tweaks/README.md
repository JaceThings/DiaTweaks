# Tweaks

Every tweak DiaTweaks adds to Dia. Turn them on and off in **Dia → Settings → Patches**, or with the [`diatweaks` command](../../README.md#the-diatweaks-command).

## Page

| Tweak | What it does |
|---|---|
| [Edge-to-edge web content](edgeToEdge.md) | Removes the padding between pages and the window edge |
| [Square corners by the sidebar](squareSidebarCorners.md) | Pages meet the sidebar with straight edges |

## Toolbar

| Tweak | What it does |
|---|---|
| [Hide toolbar](hideToolbar.md) | Hides the address bar, navigation buttons and extensions |
| [Reveal toolbar on hover](revealToolbarOnHover.md) | Shows the hidden toolbar when the pointer is at the top of the page |
| [Hide sidebar button](hideSidebarButton.md) | Hides the sidebar button |
| [Hide Chat button](hideChatButton.md) | Hides the Chat button in the toolbar |

## Sidebar and tab bar

| Tweak | What it does |
|---|---|
| [Hide Chats button](hideChatsButton.md) | Hides the Chats button in the tab bar or sidebar |
| [Hide recent tabs button](hideRecentTabsButton.md) | Hides the recent tabs button in the tab bar or sidebar |

## Commands

A command runs once each time you choose it. There's nothing to turn on.

| Command | What it does |
|---|---|
| [Group Tabs by Domain](groupTabsByDomain.md) | Groups a window's tabs by site |

## Adding a tweak

Copy [_template.md](_template.md) to `<key>.md`, add its screenshots to `images/`, and add a row for it above. See [CONTRIBUTING.md](../../CONTRIBUTING.md#documenting-a-patch).
