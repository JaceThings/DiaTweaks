# Edge-to-edge web content

Dia leaves a thin gap between the page and the edges of the window. This tweak removes it, so the page reaches the edges.

## Turn it on

It's on by default. Open **Dia → Settings → Patches** and switch on **Edge-to-edge web content**. Or run:

```sh
diatweaks enable edgeToEdge
```

## Works with

[Square corners by the sidebar](squareSidebarCorners.md) only works with this on.

## FAQ

<details>
<summary><strong>Why is the gap back when Chat is open?</strong></summary>

With Chat open, Dia shows the page as a card next to it. Edge-to-edge steps aside until you close Chat.

</details>

<details>
<summary><strong>What happens in full screen?</strong></summary>

The page reaches the edges of the screen, and its corners there are square.

</details>
